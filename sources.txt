# sources.txt — liste des sources à intégrer dans le second cerveau
#
# Une URL par ligne. Les lignes vides et celles qui commencent par # sont ignorées.
# Traitement : ./pull_sources.py   (voir --help). Les sources déjà traitées sont
# enregistrées dans sources.done.tsv et ignorées aux passages suivants (--force URL pour refaire).
#
# Vidéos (-> secondBrain/raw/youtube/) :
#   https://youtu.be/<id>  ou  https://www.youtube.com/watch?v=<id>
#   https://www.youtube.com/playlist?list=<id>     toutes les vidéos ; les nouvelles seront prises aux passages suivants
#   https://www.youtube.com/@<nom>/videos          idem pour une chaîne (limiter avec --max-new)
#   option :  | matière=<nom de la matière>        renseigne meta.md
#
# Livres (-> secondBrain/raw/pdfs/<catégorie>/<ouvrage>/) :
#   https://app.turath.io/book/<id>                UN SEUL lien suffit : le texte vient de turath, et le TXT
#                                                  du scan (tashkeel de l'édition + notes du محقق) est
#                                                  téléchargé automatiquement depuis le même fonds (Hugging Face)
#   options :  | catégorie=<matière>  | ouvrage=<nom du dossier>  | pdf=oui   (copier aussi les PDF, hors git)
#   Un lien aljam3.com est accepté mais ignoré : donner le lien turath du même livre.
